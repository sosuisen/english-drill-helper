# English Drill Helper

「復習」は大事なのであえて一番最後のアクティビティに分けてある。

ファイル（ユニット）には複数のドリル含まれるものとする。

- 準備する
  - [x] 決められた音声フォルダで始める
    - 音声フォルダを自由に1つ登録する
      - 
        - 2つ目以降のフォルダを追加する
- ドリルを選ぶ
  - [x] ユニット一覧から選ぶ
    - wavファイルでも一覧から選ぶことができる。
      - 前回終えたユニットの次から始める 
- ドリルを再生する
  - [x] ファイルを最後まで再生する
    - 現在の再生ドリルをリストで確認できる
      + ドリルをクリックすると、ドリル冒頭から再生できる
      - 直前に再生されたドリルの冒頭からリピート再生する
        + ひとつ前、ひとつ次のドリルから再生する
        - 再生速度を変えて、ゆっくりまたは速く聞く
            - ステレオ音声のファイルも正しく再生できる。
- ドリルを確認する
  - [x] 最終再生日時を確認できる
    - 
      - 終えたユニットに完了チェックを入れる
        + 苦手なドリルに苦手チェックを入れる
        + 苦手なユニットに苦手チェックを入れる
        - 自分の発音を録音し、手本の音声と聞き比べる
          - 終えた個別のドリルにも完了チェックを入れる
- ドリルを復習する
  - [x] 前回終えたユニットを繰り返す
    - 
      - 苦手チェックしたユニットから選ぶ
        + 苦手チェックしたドリルから選ぶ
