# English Drill Helper

「復習」は大事なのであえて一番最後のアクティビティに分けてある。

- 準備する
  - [x] 決められた音声フォルダで始める
    - 音声フォルダを自由に1つ登録する
      - 
        - 2つ目以降のフォルダを追加する
- ドリルを選ぶ
  - [x] 音声ファイル一覧から選ぶ
    - 
      - 前回終えたドリルの次から始める 
- ドリルを再生する
  - [x] ファイルを最後まで再生する
    - 直前に再生されたセグメントの冒頭からリピート再生する。
      + ひとつ前、ひとつ次のセグメントから再生する
        - 再生速度を変えて、ゆっくりまたは速く聞く
- ドリルを確認する
  - 最終再生日時を確認できる    
    - 
      - 終えたドリルに完了チェックを入れる
        + 苦手なドリルに苦手チェックを入れる
        - 自分の発音を録音し、手本の音声と聞き比べる
- ドリルを復習する
  - 前回終えたドリルを繰り返す
    - 
      - 苦手チェックしたファイルから選ぶ
